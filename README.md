# Training Planner

A lightweight starting point for a training-planning application.

## Project structure

- `docs/` — product and design decisions
- `src/` — static application markup, styles, and scripts
- `assets/` — images, icons, and other static assets

## Run locally

Open `src/index.html` in a browser. The project uses plain HTML, CSS, and
JavaScript and does not require a build step.

## Planning documents

See the documents in `docs/` for assignment criteria, user flows, screen
contracts, the component inventory, and Figma decisions.
